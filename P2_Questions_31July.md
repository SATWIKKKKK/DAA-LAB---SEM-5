# DAA Lab — Assignment 2 (31 July)

## P2.1 — File Handling
Write a C program to read the contents of `input.txt` using `getc()` and display them on the screen. Handle the case where the file cannot be opened.

## P2.2 — Command Line Arguments
Write a C program to accept integers as command line arguments, display `argc`, convert each using `atoi()`, add 1, and print the result.

## P2.3 — Measuring CPU Execution Time
Write a C program to measure the CPU execution time of 50000 iterations (using `clock()` and `CLOCKS_PER_SEC`) and print it in seconds.

## P2.4 — Insertion Sort
Write a C program to implement Insertion Sort. Accept the size and elements from the user, sort them in ascending order, and print the sorted array.
